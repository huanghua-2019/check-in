# 近义辨析卡 填写规范

## 要解决什么

词库里已经列了同义词，但**没说什么时候用哪个**。
"堪称 / 称得上 / 算是 / 可以说是"四个词，正式度、强度、语体都不同，写作者真正的痛点不是"不知道有词"，是"知道有词但选不准"。

辨析卡就是把这一层补齐。

## 输出格式

写文件 `build/wordpatch/diff_<分片>.json`，UTF-8，`ensure_ascii=False`，是一个**数组**：

```json
[
 {
  "word": "堪称 / 称得上 / 算是 / 可以说是",
  "syn": "正式度与力度：堪称 ＞ 称得上 ＞ 算是 ＞ 可以说是",
  "mean": "「堪称」最重，用于极有把握的高度评价，常见于书面与行业分析；「称得上」语气略缓，仍属正式判断；「算是」带让步意味，表示勉强够格，偏口语；「可以说是」最松，用于铺垫性表述，正式度最低。前两个后面常接名词性成分（堪称典范/称得上标杆），后两个可接小句。",
  "example": "评级机构的商业模式堪称顶尖。｜这家公司的成本控制称得上行业标杆。｜在当年，这算是相当激进的选择。｜这可以说是价值投资最核心的一条。",
  "scene": "写企业评价时，下定论用「堪称」；需要留半分余地用「称得上」；不确定或带调侃用「算是」。",
  "use": ["✍️ 写作技法"],
  "tier": "核心"
 }
]
```

## 各字段要求

| 字段 | 要求 |
|---|---|
| `word` | 辨析组名，用 ` / ` 连接 2~4 个词，**必须都是词库里真实存在的词或常见表达** |
| `syn` | **一句话选词口诀**，≤30 字。给出**可比较的轴**（正式度 / 力度 / 语体 / 搭配），让人一眼记住排序 |
| `mean` | 详细辨析，**60~140 字**。逐词说清：①正式度或力度 ②典型搭配 ③使用限制。**必须点出差别，不能写成"都表示……"** |
| `example` | **每个词各一个短句**，用 `｜` 分隔。句子要长短相当、语境接近，方便横向对比 |
| `scene` | 一句话决策指引：**什么场合选哪个**，≤45 字 |
| `use` | 数组，1 个（偶尔 2 个）。从下面挑：`🎯 立论判断` `🔗 论证推理` `⚖️ 对比转折` `📊 举证说明` `🔍 洞察本质` `⚠️ 警示风险` `🏆 竞争格局` `👥 人性心理` `🏗️ 管理组织` `💰 投资决策` `🌿 人生修养` `🧩 用词精准` `📐 概念指代` `✍️ 写作技法` |
| `tier` | 固定写 `"核心"` |

## 质量红线

1. **严禁编造差别**。如果两个词差别确实很小，就老实说"差别主要在语体，XX 更书面"，**不要硬编出三条不同**。
2. **严禁抄袭词典套话**。要写成一个懂中文写作的人给同事讲的话，不是《现代汉语词典》条目。
3. 每个例句必须**语法正确、语义自洽、能独立看懂**，不许写"XXXX"这类占位。
4. 一组里的词**必须真的在同一语义场内**，不要把不相干的词硬凑成一组。
5. `syn` 和 `mean` 不能重复表达同一件事。

## 选题

候选词从 `build/wordtodo/diff_seed.json`（715 个词条，含各自现有的同义词）里挑，
也可以加入你判断他一定会写混的常见组。

**优先选**：①词库里已经互列为同义词但语义不完全等价的；②投资/商业写作里的高频易混词；③正式度差异明显的同族词。
**不要选**：纯同义词（差别为零的，没有辨析价值）；冷僻词。
