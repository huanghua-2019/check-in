## 怎么打卡（腾讯文档无按钮字段，需手动）

> ⚠️ **腾讯文档多维表格没有「按钮」字段类型**，自动化也只支持「发送消息提醒」，不支持「修改字段值」。所以没法一键 +1。以下是在腾讯文档里最实用的打卡方式：

### 方式 A：直接改数字（最简单）

1. 点某个词的「**打卡次数**」单元格 → 数字 +1（比如 0→1，1→2）
2. 同一行「**最近使用**」单元格 → 输入今天日期（或选「当前时间」）
3. 如果「首次使用」为空 → 填上今天日期

> 手机端操作：点单元格 → 弹出编辑框 → 改数字/日期 → 确认。

### 方式 B：加「复选框」辅助筛选（推荐搭配）

加一个「复选框」字段名叫「今日打卡」：
1. 表最右侧「+」→ 字段类型选「**复选框**」→ 命名 `今日打卡`
2. 打卡时勾选复选框 + 把打卡次数 +1 + 填最近使用日期
3. 设筛选：`今日打卡` **不勾选** → 已打卡的行自动从视图消失，只看还没打的词
4. 每天用完后取消全部勾选（第二天重新打）

> 复选框+筛选是腾讯文档官方推荐的「打完即消失」技巧，可以聚焦注意力到还没练的词上。

## 筛选与分组（一眼看进度）

### 筛选 · 只看还没练过的词
- 工具栏「**筛选**」→ `打卡次数` **等于** `0` → 只显示未打卡的词。

### 分组 · 按分类看进度
- 工具栏「**分组**」→ 选 `分类` → 每个分类可折叠，看各类打卡进度。
- 已有的「按分类打卡」看板视图，进去后把**分组字段设为「分类」**即可。

### 排序 · 最该练的排前面
- `打卡次数` 升序 → 次数为 0 的词排最前。

> 筛选/分组是**视图级**设置，设好一次永久保留、手机电脑同步生效。

## 和"网页版打卡"对比

| | 腾讯多维表格 | 自建网页 App |

| 跨设备同步 | ✅ 云端原生，零配置 | 需接 Supabase（填 key 即用） |
